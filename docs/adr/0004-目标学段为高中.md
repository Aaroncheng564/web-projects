# ADR-0004：目标学段为高中

- 状态：已接受
- 日期：2026-09-22

## 背景

项目口述的定位是「中国初中和高中化学」，但设计文档（20–43 号）的实际范围需要核实。经全文词频与逐条比对：

| 词 | 出现次数 |
| --- | --- |
| 高中（含「高中化学」14 次） | 21 |
| 高考 | 14 |
| 初中 | **2** |
| 初中化学 | **0** |
| 中考 | **0**（3 处命中全是「期中考试」的子串） |
| 义务教育 | 0 |

支持高中范围的硬证据：

- 知识图谱的输入明确锁定高中课标与教材：教育部《普通高中化学课程标准（2017 年版 2020 年修订）》+ 人教版高中化学必修 1/2 + 选择性必修 1–3（42 号）
- 出题与诊断的 System Prompt 明文约束：「知识点必须为**高中**化学内容」（27 号）、「资深高中化学教师」（25 号）
- 真题库 = 历年高考真题 + 模拟题，示例试卷为「2020 年全国卷高考化学试卷」（25 号、34 号）
- 8 个知识点 category 的子项（盐类水解、原电池/电解池、物质的量、勒夏特列原理、同分异构体、酯化反应）全部属高中选择性必修内容

「初中」仅有的两处出现，都不是服务对象：

1. **34 号数据模型**：班级记录含「所属学段（高中/初中）」字段——数据模型**预留**了初中
2. **42 号知识图谱**：语句级拆分样本的分布「初中 5 条、高中必修 8 条、高中选修 7 条」——初中占比很小

设计文档**没有**任何「不在范围：初中内容」式的显式边界声明，它是通过只写高中课标 / 高中教材 / 高考真题来**隐含界定**学段的。

## 决策

1. **本项目的目标学段是高中。** 项目文档按此表述。
2. **数据模型保留学段字段**（如 34 号的班级「所属学段」），但**不往知识库与题库写入任何初中内容**。
3. **不在项目文档中宣称覆盖初中**。口述定位与设计文档范围不一致时，以文档为准（依据 [ADR-0001](0001-设计文档冲突的裁决优先级.md) 第 3 条）。
4. 若产品确要覆盖初中，那是一次**范围扩展**：先扩充知识图谱（42 号）与题库（25 号）到初中，再改本 ADR，**不是先改文案**。

## 影响

- `CLAUDE.md` 的目标用户由「中国初中和高中化学教师、学生及家长」改为「中国高中化学教师、学生及家长」。
- 42 号知识图谱中已存在的少量初中语句**不删除**，但不得作为服务范围的依据。
- 后续若有人问「为什么不做初中」，指向本 ADR，不要重新论证一遍。
